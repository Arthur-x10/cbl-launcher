CUBE LAUNCHER v0.6.0

CBL

一块草方块，装下整个世界

CBL 是面向 Minecraft: Java Edition 的本地启动器。 免配置 Java、四加载器、整合包导入、三路登录，以及按机器自动分配内存。

下载 Windows 版 查看能力
Windows 10 / 11 x64 绿色便携，exe 旁生成 .minecraft 不托管、不分发游戏本体

FEATURES

启动之前，环境已经准备好

一页说清版本、加载器、Java 和整合包，不再把安装流程拆成互不相关的栏目。

内置官方 Java

自动下载 Mojang 运行时：jre-legacy、java-runtime-gamma、java-runtime-delta，按游戏版本匹配 Java 8 / 17 / 21。

四大加载器

Forge、Fabric、Quilt、NeoForge 列在同一安装流程里。可查看对应游戏版本的构建。

整合包导入

支持 Modrinth .mrpack，以及 CurseForge / MultiMC / Prism 的 zip。

三路登录

离线进档、内置浏览器完成微软授权、LittleSkin Yggdrasil。本地皮肤与披风可写入 CustomSkinLoader，无需只依赖第三方。

自动性能

读取本机内存与 CPU，计算可用内存上限，并写入针对性的 G1GC 参数。崩溃与会话日志保存在 .minecraft/logs。

WORLDS

十四种世界，按一下就换天

发布页背景与启动器内的像素主题同源：草方块、末地、下界、深海、暮色森林、樱花林、蘑菇岛、雪原、沙漠、深暗之域、恶地、繁茂洞穴、紫水晶洞、红树林。启动器里切换即预览，保存后记住。

START

三步进游戏

不需要先装 Java，也不需要自己拼授权地址。

01

放好启动器

下载完成后直接打开即可，无需安装。

02

选登录方式

离线、微软正版或 LittleSkin。微软登录在窗口内完成，授权回跳由启动器截获。

03

装版本或导入包

选择原版并加加载器，或直接导入整合包。Java 会按版本自动就位。
